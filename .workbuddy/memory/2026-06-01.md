## 修复键盘弹起后发送按钮超出边界（第四次修复）
- **问题**: 前三次修复后仍然存在——对话过程中键盘弹起，发送按钮超出屏幕边界
- **根因**: iOS Safari 上 `position: fixed` + 显式计算 `height` 不可靠。`vv.height` 计算出的高度与实际渲染不一致，导致聊天窗口底部被截断，发送按钮消失在键盘下方
- **正确方案**: 用 `top` + `bottom` 撑开替代 `top` + `height` 计算
  - JS: `chatWindow.style.top = '8px'; chatWindow.style.bottom = keyboardHeight + 'px'; chatWindow.style.height = 'auto'` — 让浏览器自然拉伸
  - CSS `keyboard-open`: 添加 `height: auto; max-height: none` 防止移动端 `height: 460px` 覆盖
  - 移除 `scrollIntoView` 调用（会与拉伸布局冲突）
- 部署: https://831aab16.zhi-chuang-tech.pages.dev → https://zhi-chuang-tech.pages.dev

## 修复聊天窗口宽度超出屏幕 + 发送按钮被挤出（第五次修复）
- **问题**: 输入框高亮聚焦后，发送按钮偏离屏幕、超出边界。手机 webview 宽度不应超过屏幕
- **根因**: 移动端 `.chat-window` 用 `width: calc(100vw - 48px); right: 12px` 在某些设备上宽度计算不准，加上 `left/right` 定位不一致导致超出视口
- **修复**:
  1. 移动端 `.chat-window` 改为 `left: 12px; right: 12px; width: auto` — 浏览器自己算宽度
  2. `.keyboard-open` 改为 `left: 0; right: 0; width: 100%; max-width: 100%; padding: 0 8px; box-sizing: border-box; overflow: hidden` — 贴边+内边距，永不超出
  3. `.keyboard-open` 子元素 padding 进一步压缩（header/messages/input-area）
  4. JS `blur` 事件和 `adjustChatForKeyboard()` 收键盘时**清除所有 inline style**，让 CSS 接管，不再残留 `bottom: 72px` / `bottom: 80px`
- 部署: https://6292a7c1.zhi-chuang-tech.pages.dev

## 取消输入框聚焦变大效果（第六次修复）
- **问题**: 输入框高亮(focus)时宽度/高度突然变大，用户要求取消所有变大效果
- **根因**: 两个东西在让输入框"变大"：(1) `Auto-resize textarea` JS 代码监听 input 事件自动撑高; (2) focus 的 `box-shadow` 外发光 + `transition` 动画可能触发移动端布局重算
- **修复**:
  1. 删除 `Auto-resize textarea` 代码块 — 不再动态改变高度
  2. `.chat-input` 改为固定高度：`height: 44px; max-height: 44px; overflow: hidden`，加上 `resize: none`
  3. 移除 `transition: var(--transition)` — 不触发动画
  4. `.chat-input:focus` 改为 `box-shadow: none; outline: none` — 聚焦只有边框颜色变化，无尺寸影响
- 部署: https://539273f0.zhi-chuang-tech.pages.dev

## 修复 iPhone 13 输入框聚焦变宽（第七次修复）
- **问题**: 前两次修复后，iPhone 13 上输入框聚焦时仍然宽度增宽
- **根因**: iOS Safari 的自动缩放行为——当 textarea/input 字号 < 16px 时，iOS 会自动 zoom in 整个页面，导致 position:fixed 的 chat-window 相对视口变宽，输入框也跟着变宽
- **修复**:
  1. `.chat-input` 字号从 `0.88rem`(≈14px) 改为 `16px` — 阻止 iOS 自动缩放
  2. 添加 `-webkit-appearance: none` — 移除 iOS 默认输入框样式
  3. `body` 添加 `-webkit-text-size-adjust: 100%` — 全局禁止 iOS 文字大小调整
