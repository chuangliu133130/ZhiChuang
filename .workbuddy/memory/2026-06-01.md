## /api/chat 405 问题总结 (2026-06-01)
- **405 根因**: Cloudflare Dashboard 中项目仍为纯静态 Pages 模式
  - Pages Functions 未启用 → `functions/` 目录不执行
  - Pages _worker.js 高级模式未启用 → `public/_worker.js` 被忽略
  - AI/KV 绑定未配置 → 即使 Functions 启用也无 AI 能力
- **尝试过的修复**:
  1. wrangler.jsonc 删除 main 回退 Pages 模式 → 无效（Dashboard 不按 wrangler.jsonc 配置）
  2. _routes.json 指定 API 路由 → 无效（Functions 未启用）
  3. public/_worker.js 高级模式 → 无效（需 Dashboard 启用）
  4. wrangler deploy → 失败（OAuth token 过期）
- **当前状态**: 前端 localChatReply 降级方案正常工作
  - API 返回 405 → 前端检测非 JSON → 自动使用本地关键词匹配
  - 用户打开网站聊天不会看到错误，看到的是正常的客服回复
  - 代价是没有 AI 智能回复，只能关键词匹配
- **根治方案**: 需要登录 Cloudflare Dashboard → Pages → zhi-chuang-tech:
  1. Settings → Functions → 启用 Pages Functions
  2. Bindings → 添加 KV: ZC_LEADS, 添加 Workers AI: AI
  3. 重新部署一次
