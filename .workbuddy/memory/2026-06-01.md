## 修复键盘弹起后发送按钮超出边界（第四次修复）
- **问题**: 前三次修复后仍然存在——对话过程中键盘弹起，发送按钮超出屏幕边界
- **根因**: iOS Safari 上 `position: fixed` + 显式计算 `height` 不可靠。`vv.height` 计算出的高度与实际渲染不一致，导致聊天窗口底部被截断，发送按钮消失在键盘下方
- **正确方案**: 用 `top` + `bottom` 撑开替代 `top` + `height` 计算
  - JS: `chatWindow.style.top = '8px'; chatWindow.style.bottom = keyboardHeight + 'px'; chatWindow.style.height = 'auto'` — 让浏览器自然拉伸
  - CSS `keyboard-open`: 添加 `height: auto; max-height: none` 防止移动端 `height: 460px` 覆盖
  - 移除 `scrollIntoView` 调用（会与拉伸布局冲突）
- 部署: https://831aab16.zhi-chuang-tech.pages.dev → https://zhi-chuang-tech.pages.dev
